# 블로그 도우미 판매 페이지

네이버 블로그 관리 프로그램의 독립 판매 웹사이트입니다. 데스크톱 앱, 계정 처리 API, 사용자 데이터는 포함하지 않습니다.

- 일시불: **450,000원**
- 월 구독: **50,000원 / 월**
- 반응형 제품 소개, 인터랙티브 데모, 요금 선택, FAQ
- Next.js · React · TypeScript · Tailwind CSS

## 로컬 실행

Node.js 22.12 이상이 필요합니다.

```bash
npm ci
npm run dev
```

루트 경로와 /sales에서 판매 페이지를 제공합니다.

## 배포

Vercel에서 이 저장소를 Import하고 배포합니다. 빌드 및 출력 설정은 vercel.json에 포함되어 있습니다. 저장소 연결 후 기본 브랜치 변경 사항이 자동으로 배포됩니다.

`npm run build`는 정적 사이트를 out/에 생성하므로 다른 정적 호스팅에서도 사용할 수 있습니다.

## 구매 링크

호스팅 프로젝트의 환경 변수에 각 결제 페이지의 HTTPS URL을 넣고 재배포하세요.

- SALES_ONE_TIME_URL: 일시불 구매 링크
- SALES_MONTHLY_URL: 월 구독 구매 링크

링크가 없으면 해당 요금제의 구매 버튼에 '구매 연결 준비 중'을 표시합니다. 이 사이트는 결제 자체를 처리하거나 구독을 관리하지 않습니다. 제품 미리보기의 계정과 수치는 예시 데이터입니다.
